# Daily Balance

Daily Balance is a web application designed to help users **track and improve their well-being**.  
It combines journaling, AI-powered analysis, and social features to provide insights into daily activities and their impact on overall health.

## Features
- **Track & Improve Well-being**: Journal daily activities to monitor lifestyle patterns.  
- **AI Analysis**: Evaluate the impact of activities on psychological, cognitive, physical, and social well-being.  
- **Points System**: Activities receive positive or negative points based on their effect.  
- **Progress Dashboard**: Visualize progress over time and connect with friends.  
- **General Suggestions**: Get AI-generated advice to improve well-being.  

## Tech Stack
- **Frontend**: React  
- **Backend**: Express.js  
- **Database**: MongoDB (Atlas)  
- **AI Integration**: Gemini API
